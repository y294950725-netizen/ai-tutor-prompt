设计理念
为什么通用大模型不能直接当老师
核心洞察：初中数学辅导的核心矛盾是——学生缺的不是知识点，而是"从题目到解法"的思维过程。通用大模型最大的问题就在于跳过了这个过程，直接输出完整解题步骤。

两大创新机制

机制一：错误分类系统

不同类型的错误需要完全不同的应对——概念错用反例、策略错让学生走到死胡同、计算错直接指出。精准分类 → 精准应对，这才是"像真人老师"的关键。

机制二：元认知训练

传统辅导教"怎么做题"，我们教"怎么思考"。做完题后引导学生定位卡点、归因分析、迁移策略——让学生从"被动接受引导"转向"主动监控自己的思维过程"。

策略性错误 设了错误的未知数 不马上指出，让学生走到死胡同再回头
计算性错误 移项变号出错 直接指出具体哪一步算错

好辅导 vs 坏辅导

❌ 坏辅导（直接输出）
"设乙的速度为x km/h，则甲的速度为1.2x km/h，由题意得方程..."
✅ 好辅导（引导式）
"这道题里出现了甲和乙两个人，他们各自有什么信息？我们先整理一下。"

递进式引导策略

卡点A1 — 条件提取障碍 ▼
引导级别1（轻推）
"你先把题目读一遍，告诉我这道题里出现了哪些人/物？每个分别有什么信息？"
引导级别2（脚手架）
"我们画一个表格，横排写甲和乙，竖排写速度、时间、路程，你能填进去吗？"
引导级别3（具体化）
"'甲比乙快20%'——如果乙的速度是v，那甲的速度怎么用v表示？"
卡点A2 — 设未知数困难 ▼
引导级别1
"这些量里面，哪个是题目直接问你求的？"
引导级别2
"你觉得哪个量最不容易直接算出来？我们就设它为x试试。"
卡点A3 — 等量关系缺失 ▼
引导级别1
"题目里还有哪句话你没用到？那句话说的是什么关系？"
引导级别2
"'甲比乙早到30分钟'——这说明谁的时间长、谁的时间短？差多少？"

错误分类实战

错误类型学生的错误AI的应对
概念性"甲是乙的1.5倍"写成"甲=乙+1.5""如果乙=10，1.5倍是15，+1.5是11.5，哪个对？"
策略性设路程为x（后续表达困难）让学生走，走不动时："换个量设x会不会更方便？"
计算性通分时分子算错"方程列得很好。通分那一步你再算一遍。"

几何证明题（全等 / 相似三角形）

场景画像：逻辑推理要求最高的题型。核心不是计算，而是从已知条件出发，通过严密的逻辑链到达结论。思考方向往往是逆向的。

学生卡点图谱

编号卡点具体表现深层根因占比
G1不知道从哪入手"这题怎么证啊？"只会正向思考，不会逆向分析~35%
G2对应元素找不全找不齐SAS/ASA需要的三组对应不会系统地在图中搜索~25%
G3辅助线恐惧不知道加在哪里缺乏辅助线模式积累~20%
G4书写跳步/混乱"因为AB=CD所以全等"不理解证明格式即逻辑~20%

❌ 坏辅导
"作辅助线EF∥BC，由平行线性质可得∠1=∠2..."
✅ 好辅导
"结论让你证什么？要证它，你需要什么中间结论？"

老师

二次函数压轴题（含动点 / 分类讨论）

场景画像：中考"最后一道题"，通常分(1)(2)(3)三个小问。本质是考察学生拆解复杂问题的能力。辅导难点在于畏难情绪和不会拆解。

编号卡点具体表现深层根因占比

F2动点参数化困难不会用t表示P的坐标缺乏"运动→参数"思维~25%
F3分类讨论不全只考虑一种情况不理解为什么要分类~30%
F4小问之间脱节第(2)问从头做起不理解压轴题递进设计~25%

✅ 好辅导
"先别慌，第(1)问在问什么？我们一步一步来。"

B

模块三：产品级落地说明
技术限制、产品考量与未来扩展

图形交互限制

当前大模型在几何题场景下存在固有限制——无法在图上标注、无法让学生上传手写标记。

建议：产品层面提供简易画板工具（类似 GeoGebra），学生在画板上操作，AI 通过 API 获取图形信息。画板不可用时，通过 Skill 2 的"图形口述协议"降级处理。

多 Skill 协同

压轴题等复杂题型可能在一道题内跨 Skill 调度。

推荐方案：用 Tool Use 实现——主 Prompt 作为 controller，根据当前步骤类型调用不同 Skill 的 tool，上下文通过 function calling 自然传递。

效率模式的产品考量

AI 家教的核心矛盾是"教学质量 vs 用户留存"。学生赶作业时强行引导会导致用户流失。

平衡策略：效率模式降低引导深度但不降到"直接给答案"，在保留最低教学价值的同时满足用户效率需求。
